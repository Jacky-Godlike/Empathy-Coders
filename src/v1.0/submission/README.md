## What must be completed before submitting

1. **Leader contact.** Add the team leader's email and phone to Section 1 of both
   the Proposal and the Technical Declaration. The current PDF says
   `[TO BE COMPLETED BEFORE SUBMISSION]`.
2. **Replit links.** The live deployment URL is already filled in the Technical
   Declaration and the root `README.md`. Add the exact Replit project URL from the
   Replit address bar (the current PDF says `[COPY FROM THE REPLIT ADDRESS BAR]`).
   The Preliminary PDF does not have a Replit URL field.
3. **Replit proof.** Deploy the app, take the three screenshots described in the
   proof PDF, and replace the dashed boxes. The screenshots must show the team's
   own account, the OrderPilot project name, the deployment URL and the project
   history or credit usage. **Do not show any API key value.**
4. **Signature.** The team leader signs the Proposal and the Technical Declaration.
   The date can stay as 21 October 2026 or be updated to the submission date.
5. **Team confirmations.** Every member must confirm the workshop attendance, the
   IP declaration and the employment-IP declaration before the leader signs.
6. **Slide and video links.** Add the final slide deck and YouTube pitch video
   links to the root `README.md` and the official submission form.

## RunPod

RunPod was **not used**. OrderPilot is a CPU-only Node.js/Express app; the AI model
is a hosted API. There is no Pod, endpoint, GPU type or usage record. The
`SDC2026_EmpathyCoders_RunPod_NotUsed.pdf` declaration makes this explicit. The
official RunPod proof is required only when the project uses GPU compute.

## Secrets

- The repository must not contain `.env`, API keys, passwords or tokens.
- The Replit proof screenshots must not show any key value.
- The AI key belongs in Replit **Secrets** (or a gitignored `.env` locally).
- Before submitting, search the repository for `AI_API_KEY`, `sk-` and `AIza` and
  confirm that only `.env.example` placeholders appear.

## Validation

The PDFs are generated by [`../scripts/generate_submission_pdfs.py`](../scripts/generate_submission_pdfs.py).
The script prints the word count for every limited section and fails if a section
exceeds its limit. To regenerate after editing the team details:

```bash
uv run --with 'reportlab==4.2.5' python scripts/generate_submission_pdfs.py
```

The app's test suite is separate:

```bash
npm test
```
